# Life Git

> Một repository dùng Git để ghi lại lịch sử công việc, dự án và các sự kiện có ý nghĩa trong cuộc đời.

## Mô hình

- **main** = dòng đời / sự nghiệp
- **branch** = một job, dự án hoặc hướng thử nghiệm
- **commit** = một sự kiện, quyết định, cột mốc hoặc trải nghiệm
- **merge** = kinh nghiệm / kỹ năng / giá trị được giữ lại trong main
- **close branch** = kết thúc một công việc hoặc hướng đi

## Nguyên tắc

Không phải mọi sự kiện đều cần commit.

Chỉ commit những thay đổi hoặc cột mốc đáng lưu lại.

Một branch có thể được mở, theo dõi, đánh giá và đóng mà không cần merge toàn bộ branch vào main.

## Workflow

OPEN BRANCH → COMMIT → REVIEW → KEEP / MERGE / CLOSE

## Mục tiêu

Repository này không phải source code.

Nó là **version control cho lịch sử công việc và sự nghiệp**.

Git lưu code history.

Life Git lưu life/career history.
